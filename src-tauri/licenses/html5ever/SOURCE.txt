The application source includes these original archives in upstream/servo-html5ever
and the modified crates in src-tauri/vendor. Kiwix replaced the tokenizer's
data-state intrinsics and unchecked string slices with checked Rust operations
and added a regression test. Both modified libraries forbid unsafe Rust in
their own code. Their storage and other dependencies retain their own implementations.
