# Stopwords ISO

The 58 files in `data/stopwords` are copied from [jasontitus/xapianbuilder at 13ff3689](https://github.com/jasontitus/xapianbuilder/tree/13ff368991850f35ecb2e60037c6385d9992cbdc/data/stopwords). That project verified their hashes against the upstream [Stopwords ISO collections](https://github.com/stopwords-iso). The Gujarati list uses [the Gujarati notice](Stopwords-ISO-gu-MIT.txt). All other lists use [the Gene Diaz notice](Stopwords-ISO-MIT.txt). Include both notices when redistributing the embedded lists.

## Unicode search data

The property and decomposition tables under `src/unicode/` derive from ICU4X 2.4.0 compiled Unicode 18.0.0 data. Redistribute [the Unicode notice](Unicode-3.0.txt) with the tables.
