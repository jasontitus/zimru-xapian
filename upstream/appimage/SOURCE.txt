Run recipe/rebuild.sh on an x86-64 Linux Docker host to reproduce and
compare the retained bytes. The Dockerfile pins the Alpine base image,
146 Alpine package versions and the libfuse and squashfuse archives.
Rebuilding requires access to those versions in the signed Alpine
repositories or an equivalent retained package mirror.

The native bootstrap uses FUSE/squashfuse to mount the installed package.
Explicit extraction and no-FUSE launch use /usr/bin/unsquashfs from the
Ubuntu squashfs-tools package. The bootstrap verifies temporary directory
ownership and allocates each automatic extraction with mkdtemp. It
retains the selected image across inspection and native subprocesses.
An explicit extraction requires a fresh squashfs-root in a trusted
working directory. Other users cannot write optional portable sidecars.

The original upstream libfuse 3.15.0 and squashfuse 0.5.2 source archives
match the digests in scripts/common/install-dependencies.sh of the
retained upstream source. The original libfuse patch is inside that archive.
The native bootstrap is statically linked with musl, zlib, zstd, mimalloc,
libfuse and squashfuse. LICENSE preserves the upstream notice and terms.
